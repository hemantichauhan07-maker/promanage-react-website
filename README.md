# ProManage - React Project Management Website

ProManage is a modern and responsive project management website built using React. The project includes multiple pages with a clean user interface for presenting project management services, features, registration, and login functionality.

## 🚀 Features

- Responsive navigation bar
- Home page with hero section and call-to-action
- About Us page
- Services page
- Contact Us page
- User Registration page
- User Login page
- Project management service cards
- Responsive and clean UI
- Reusable React components
- Modern layout and styling

## 📄 Pages

### 🏠 Home
Includes:
- Hero section
- Project management introduction
- Why Choose Us section
- Call-to-action section
- Footer

### 👥 About
Includes:
- About Us section
- Company/project introduction
- Project management course/service cards
- Enroll Now buttons

### 🛠️ Services
Includes:
- Workouts
- Community
- Membership
- Events
- Service cards with More buttons

### 📞 Contact
Includes:
- Contact form
- Call Us information
- Location information
- Working hours

### 📝 Register
Includes:
- Registration form
- Full Name
- Email
- Phone
- Plan selection
- Register Now button
- Project feature cards

### 🔐 Login
Includes:
- Username field
- Password field
- Remember Me option
- Login button
- Forgot Password link
- Create New Account link

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Bootstrap / CSS Styling
